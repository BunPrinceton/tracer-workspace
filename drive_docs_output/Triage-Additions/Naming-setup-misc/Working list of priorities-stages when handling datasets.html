Method 1: Geometry Nodes (Best for 3.6+) 

  1. Import Points: Import your point cloud (e.g., File > Import > Stanford (.ply)).
  2. Add Modifier: With the points selected, add a Geometry Nodes modifier.
  3. Create Geometry Node Tree: Use the following nodes: Points to Volume 
  4. →right arrow
  5. → Volume to Mesh.
  6. Adjust Resolution: Increase the resolution in "Points to Volume" to capture detail, but be cautious of high memory usage.
  7. Refine: Add Decimate and Smooth nodes/modifiers to clean up the mesh.

Method 2: Add-ons & External Tools

  • Point Cloud to Mesh Add-on: A dedicated addon for Blender that allows selecting meshing algorithms directly in the viewport.
  • MeshLab: For complex, large-scale point clouds, exporting to MeshLab for Poisson Surface Reconstruction and then importing back to Blender is often preferred.

  • Creates a database filled with distribution profiles that outline statistics about supervoxel volume, synapse count, and cable length, etc. These could be viewed as a lens into what typically gets added to cells at a granular level and at a broad level. e.g. segments of x length y size and n synapse count are the most likely to get added to a randomly selected cell. Specific cell types could be viewed at an individual level or all together post proofreading to see if they compare with generalized proofreading distributions across all cells in that dataset or specific other cell types or even their mirrored type (e.g. left side vs right side TmY cells). Personalized distributions could be useful as an indicator for training and a fun stat for proofreading profiles. e.g Tracer A is good at finding smaller pieces but struggles with longer segments and is the best Dm2 tracer. With these distributions it’s possible we could recognise a pattern and come up with a smarter targeted list of “likely to be added under normal circumstances” segments. Beyond that we can create specific tasks with cell types that often have specific segment profiles that need adding and offer it as practice for people who struggle with those types of added segments or on the other hand, give it to experts of that segment profile.
