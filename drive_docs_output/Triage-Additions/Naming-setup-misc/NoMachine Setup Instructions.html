NoMachine Remote Setup Instructions

  1. Setup Secure Remote Access (SRA) VPN
  1. Setup needs to be done on your home device(s): https://workcontinuity.princeton.edu/remoteaccess
  2. Connect to the Princeton network following steps described in the link above

  1. Setup PNI machine (Ubuntu)
  1. SSH to your workstation - look up the name heret
  1. Windows 10
  • In the start menu, enter powershell and open it
  • ssh username@seungworkstationXX.princeton.edu (replace user and workstation name)
  • It will ask for your PNI password
  1. MacOS / Linux
  • Launch the Terminal application (Command + Spacebar, enter Terminal)
  • ssh username@seungworkstationXX.princeton.edu (replace user and workstation name)
  • It will ask for your PNI password
  1. Verify that you are connected to your PNI workstation (You should see a command prompt starting with username@seungworkstationXX:~$)
  2. Download NoMachine

wget http://download.nomachine.com/download/6.11/Linux/nomachine_6.11.2_1_amd64.deb

  1. Install NoMachine

sudo dpkg -i nomachine_6.11.2_1_amd64.deb

  1. Setup Home machine
  1. Download & Install OS-specific version

MacOS, Windows and Linux versions are all here: https://www.nomachine.com/download

Installation for Windows is pretty straightforward - MacOS probably too(?), don’t think anybody uses Linux at home

  1. Connect from home to PNI using NoMachine
  1. Click Continue on the welcome window
  2. Click New in the Recent connections panel (
  3. Click Continue on the Protocol tab (keep NX as protocol)
  4. Enter seungworkstationXX.princeton.edu as Host, and keep Port 4000
  5. Click Continue on the Authentication tab (Password is fine)
  6. Click Continue on the Proxy tab (No Proxy is fine)
  7. Give the new connection some descriptive name and press safe

  1. Troubleshooting

  • [Jay]: Just a minor addition for Windows 10 users: the SSH plugin for powershell may not function unless you manually add it to PATH (I had to). To do so:
  • On the Windows desktop, right-click My Computer.
  • In the pop-up menu, click Properties.
  • In the System Properties window, click the Advanced tab, and then click Environment Variables.
  • In the System Variables window, highlight Path, and click Edit.
  • In the Edit System Variables window, insert the cursor at the end of the Variable value field.
  • If the last character is not a semi-colon (;), add one.
  • After the final semi-colon, type the full path (by default this should be C:\Windows\System32\OpenSSH)

  • ‘The remote host refused to establish a connection’
  • Make sure you are connected to VPN and you can successfully ssh to your workstation
  • If ssh works, try running sudo service restart nxserver on the PNI workstation
