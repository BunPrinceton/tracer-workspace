251210 Reviewing MEC Labels By Semantic Class

With Zetta's guidance, the Princeton team produced voxel painting labels for Eric's MEC dataset. The segmentation team could use help with a final review of the labels, organized by semantic class. This is meant to double-check the semantic labels and catch any final major errors in the segmentation that may have been overlooked.

TRACKING SHEET
Use "MEC Segmentation Label Revision" (spreadsheet 1OVbYRBYYN2oym5jlNaqaBSVhy6322UjIKacT-S7NQYA) to log information about labels in each cutout, starting from these neuroglancer links:
  1. Cell semantic v1 Link
  2. Mito semantic v1 Link
  3. Defect semantic v1 Link

PROTOCOL
Voxel Painting Cell Segmentation Protocol v1.1 (doc 1KuefhUI0hGTqZu9Mp5QlBZCrAcmB5REwyuZRamE39IE).

ESTIMATED TIME: 1-4 hours

INSTRUCTIONS
1. Check out a neuroglancer link for a cutout you have not previously worked on. It contains layers: Image; Segmentation (cell, mito, defect); Annotations with one point per segment, each point carrying the semantic class assigned from webknossos.
2. Cycle through each point and review:
   a. The semantic class.
   b. Whether the segment has any major errors:
      - Inspect the mesh for obvious merge errors, split errors, or gaps in the segment that could be connected.
      - Scroll through the 3D segmentation to inspect for large holes.
      - Do NOT worry about precision of the borders.
3. Make corrections to semantic labels directly in the annotation layer.
4. Create a new annotation layer to mark any issues with the segmentation.
5. Save the reviewed neuroglancer link back to MEC Segmentation Label Revision (Cell / Mito / Defect semantic v1 Reviewed Link).
6. Make corrections to the segmentation in webknossos:
   a. Update segment names with any semantic class corrections you made in neuroglancer.
   b. Mark "Semantic Review Required Changes in Webknossos" as "Yes" in MEC Segmentation Label Revision.
