Objective: Compare the cleft annotations between two links and assign a category number.

Basically you pull up both links, "easy-seg" and "synaptor-seg" and then go through the "FN" tab in the synaptor-seg link and assess how the annotated cleft for each listed synapse compares to the annotated cleft for the same location in the easy-seg link, before assigning it a number from a short-list of common scenarios.  The categories are:

1: Cleft Annotation present in both/But much smaller in synaptor-seg.

2: Cleft annotation present and large enough in both.

3: Cleft annotation present in synaptor-seg/ Not in easy-seg.

4: Cleft annotation present in easy-seg/ Not in synaptor-seg.

5: Cleft annotation not present in either.

  • open "zetta comparison" link (synaptor-seg) from column F as well as the "Predeiction link" (easy-seg) in column C.
  • the "zetta comparison" links don't already have the synaptor-seg tab present, so you'll need to grab that tab from one of the links in column H.
  • once that's done, go down the FN list in the zetta comparison link. For each item on the list - compare said synapse location to the same location in the prediction link,  and determine which number to give it based on the cleft annotations.
  • Write the number as a note on each item in the FN list, post your link in column H, and then record your number assignment spread in columns I-M

  ** Note that though the X & Y cordinates aren't in-sync between the two sets, the Z slice will be the same and is a quick guide for locating the same area
