Ground Truth Hub

Central reference for all Ground Truth annotation procedures, verification workflows, and quality standards.

How to Use This Section

For Scientists / Annotators

  • Start with GT Task Handling (SOP-001) for the complete annotation workflow
  • Use the GT Checklist (SOP-003) before submitting any completed task
  • Refer to Protocol Guidelines (SOP-005) when encountering edge cases

For Managers / QA Leads

  • Use GT Verification (SOP-002) to review submitted work
  • Monitor compliance via the GT Checklist (SOP-003)
  • Delegate tasks by pointing team members to GT Task Handling (SOP-001)
