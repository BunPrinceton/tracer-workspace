Manage tags

Renaming updates every image that has the tag. Deleting removes it from every image. Hotkeys follow palette order.

Keys

Tag hotkeys, in palette order: 1–6 q w e r t, then 7–0 a s d f g, then z x c v b, y u i o p, h j k l.
Enter mark this image done and go to the next one.
Shift+Enter or ← previous image · → next image without marking it.
] jump to the next image that is not done yet.
n focus the new-tag box; Enter there creates the tag and adds it to this image; Esc leaves the box.
Delete clear all tags on this image. Click the image to toggle full-size zoom.

Everything is saved in this browser immediately. "Link save file…" also writes figure-tags.json to disk after every change, so the tags survive clearing browser data and can be handed to the site build. Export/Import JSON do the same by hand.
