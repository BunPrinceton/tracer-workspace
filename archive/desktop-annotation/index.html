Desktop-Based Annotation Deprecated

VAST + Omni Workflow

The original annotation workflow used desktop applications running on Ubuntu workstations with network-mounted data storage. A single-user, file-based pipeline where annotators worked on local copies of volumes before submitting back for review.

Current: Web-based task workflow (collaborative, database-backed)

Key Differences from Current Workflow

  • Local data access vs. cloud-hosted volumes
  • Single-user vs. collaborative editing
  • File-based vs. database-backed annotations
  • Related tools: VAST, Omni
